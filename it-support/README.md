## Working method

Read the request, propose an approach, build in an isolated lab, test expected behaviour and document the evidence. Troubleshooting starts with symptoms and checks; record a root cause only after verifying it.

Use the [ticket template](tickets/TEMPLATE.md) and store redacted [screenshots](screenshots/README.md). Create short help articles in [knowledge-base](knowledge-base/README.md).
